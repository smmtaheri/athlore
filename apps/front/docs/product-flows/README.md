# فلوهای محصول Athlore

این پوشه **مرجع canonical** فلوهای مهم محصول است: رفتار واقعی از دید مربی و تیم، به فارسی و با زبان ساده.

مستندات فنی API و schema اینجا نیستند. برای قرارداد فنی به `docs/` مهندسی هر repo مراجعه کنید.

## قوانین

- هر فلو مهم جدید باید اینجا، به **فارسی**، و با ساختار یکسان اضافه شود.
- متن فلو را در چند repo کپی نکنید؛ فقط به این پوشه ارجاع بدهید.
- لحن عملی بماند (گام‌به‌گام برای استفاده)، نه توضیح کد.
- اگر UI یا رفتار محصول عوض شد، همین فایل‌ها را به‌روز کنید تا drift نشود.

## آدرس‌های رسمی محصول

- Home عمومی: `https://athlore.ir/`
- ورود و پنل مربی: `https://coach.athlore.ir/login` و مسیرهای همان دامنه
- ورود و پنل شاگرد: `https://student.athlore.ir/login` و مسیرهای همان دامنه

مسیرهای پنل روی دامنه‌ی اصلی یا دامنه‌ی نقش مقابل وجود ندارند و نباید در فلوها استفاده شوند.

## قالب فلو جدید

برای هر فلو تازه یک فایل `kebab-case.md` بسازید و این اسکلت را پر کنید:

```markdown
# عنوان فارسی فلو

یک یا دو جمله: این فلو چیست و با کدام فلوهای نزدیک اشتباه نشود.

## فلوی استفاده …

1. …
2. …
```

سپس همین فایل را در جدول بالا اضافه کنید.
