# Athlore Frontend

React and Vite single-page application for Athlore's public, coach, and
student experiences.

## Development

```bash
pnpm install
pnpm dev
```

Configuration is documented in `.env.example`. Product flows for the coach
team are in [`docs/product-flows/`](docs/product-flows/).

## Quality checks

```bash
pnpm lint
pnpm typecheck
pnpm test -- --run
pnpm build
```
